# LAB 3: Hệ Thống Quản Lý Khách Sạn (WinForms & SQL Server)

## 📌 Giới thiệu dự án
Ứng dụng desktop được phát triển bằng ngôn ngữ C# trên nền tảng Windows Forms kết hợp với cơ sở dữ liệu SQL Server, phục vụ cho việc quản lý hoạt động vận hành của khách sạn.

## ⚙️ Các chức năng chính
1. **Quản lý Danh mục & Phòng:** Thêm, sửa, xóa thông tin phòng, tiện nghi và phân loại khu vực.
2. **Đặt / Nhận phòng (`FrmDatPhong`):** Quản lý danh sách phòng trống, lập phiếu đặt phòng mới và cập nhật trạng thái phòng.
3. **Sử dụng dịch vụ (`FrmDichVu`):** Thêm các dịch vụ phát sinh cho các phòng đang có khách thuê.
4. **Trả phòng & Thanh toán (`FrmTraPhong`):** Tính toán chi phí, xử lý thanh toán và cập nhật trạng thái phòng về trống.
5. **Thống kê:** Thống kê doanh thu và danh sách phiếu đặt theo khoảng thời gian tùy chọn.
